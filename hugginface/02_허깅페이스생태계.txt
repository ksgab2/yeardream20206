Huggingface Library
Transformers : 자연어 처리 모델
Datasets : 대규모 데이터셋 로드 및 처리(스트리밍으로 효율적 처리 가능)
Tokenizer : 자르기(인식하기 좋게)
Accelerate : 하드웨어에 따른 최적화된 실행 처리
Diffuers : 이미지생성
Evaluate : 모델성능 측정 지표로 평가
PEFT : 경량 학습 방법 / 효율적인 파인튜닝 제공

# 허깅 페이스 토큰 발급 및 로그인
1. 회원가입 -> 로그인
2. 우측 상단 프로필 클릭 -> settings -> Access Tokens
-> Create new Tokens 클릭
Type 을 Read 로 설정 -> 토큰 생성 -> 복사해 둔다.
* Read : 읽기 권한
Fine-grained : 세부권한 제어
Write : 읽기 + 쓰기
